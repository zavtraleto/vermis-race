# Глоссарий: термин → идентификатор в коде

Один термин — один идентификатор. Новое понятие сначала добавляется сюда.

| Термин | Идентификатор | Пояснение |
| --- | --- | --- |
| Шаг симуляции | `DT`, `step()` | 1/120 с |
| Тик | `tick` | номер шага с начала гонки |
| Состояние гонки | `RaceState` | плоский JSON: машины, тик, RNG |
| Машина (любая) | `Car` | игрок, соперник и трафик — одна структура с полем `kind` |
| Вид машины | `kind: 'player' \| 'rival' \| 'traffic'` | |
| Путь вдоль трассы | `z` | в сегментах |
| Боковая позиция | `x` | −1…1 = асфальт |
| Скорость | `speed` | доля `vmax`; в м/с `v = speed·vmaxKmh/3.6` |
| Руль (сглаженный) | `steer` | −1…1, R203; цель — `InputFrame.steer` |
| Курс кузова | `heading` | рад, относительно касательной дороги (R200) |
| Кадр ввода | `InputFrame` | `{ steer, gas, brake, driftTap }` (R201) |
| Направление скорости | `travel` | рад, относительно касательной дороги (R200) |
| Угол заноса | `slip` | `heading − travel` (R200) |
| Скорость заноса | `slipRate` | рад/с, с запаздыванием (R207) |
| Угол колёс | `wheel` | `steer·wheelMax` + помощь R205 (за тик, не хранится) |
| Контрруль | `counter` | 0…1, ослабляет переднюю ось (R206) |
| Таймер дрифта | `driftTimer` | тики; > 0 — окно или дрифт (R208) |
| Окно дрифта | `driftWindow` | 0.66 с после `driftTap` или тапа тормоза (R208) |
| Защёлка дрифта | `slipLatch`, `driftHold` | занос > 8.4° держит таймер 0.2 с (R208) |
| Сцепление зада | `gripRear` | 0…1 (R207, R208) |
| Доворот к дороге | `railGrip`, `railDrift` | R209: поворот `travel` к дороге без потери скорости |
| Отбойник | `edge`, `edgePull` | R209, H24: у внешнего края в дрифте дуга заворачивает внутрь |
| Опорный угол | `refAngle` | R209, H25: занос, естественный для поворота впереди |
| Помощь контррулю | `wheelGo`, `assistLead` | R205, H23 |
| Вход в дрифт касанием | `driftTap`, `retouchWindow`, `retouchSteer` | R202: оторвал палец и коснулся вбок |
| Сетка управления | `pad` | R202, R214: прямоугольник X/Y в центре экрана |
| Параметры машины | `CarParams` | набор `P` из brief; JSON в `src/data/cars` |
| Счётчик вне дороги | `offTicks` | тики подряд с `|x| > 1` (R21) |
| Объекты у трассы | `roadside` | фонари (`lamp`), билборды (`billboard`), строения (`building`); R32 |
| Фигура трассы | `figure` | именованный кусок трассы из словаря R31: `straight`, `kink`, `sweeper`, `hairpin`, `flick`, `esses`, `tightening`, `opening`, `carousel`, `double` |
| Трасса | `Track` | лента сегментов |
| Сегмент | `Segment` | `{ curve, y, width, props }` |
| Кривизна | `curve` | знак: + вправо |
| Класс крутизны поворота | `curveClass: 'easy' \| 'medium' \| 'hard'` | значения в `src/data/tracks/curves.json` |
| Секция трассы | `TrackSection` | `{ enter, hold, leave, curve }` в сегментах |
| Холм | `hill` | R30: изменение высоты за секцию в длинах сегмента (+ вверх); `y` сегмента — высота в его конце, один easeInOut на всю секцию; сумма `hill` по кольцу = 0 |
| Отсечение за гребнем | `Projection.clipped` | R30: 1 = линия проекции не выше всех ближних линий, дорога и столбики за ней не рисуются |
| Объект у дороги | `Prop` | поле `layer` 2 или 3, класс коллизии |
| Класс коллизии | `collision: 'solid' \| 'destructible' \| 'none'` | |
| Поток (слипстрим) | `draft` | заряд 0…1 |
| Потолок скорости | `capMul` | максимум по источникам, не сумма |
| Соперник | rival | `kind: 'rival'`; главный соперник — `isNemesis` |
| Трафик | traffic | `kind: 'traffic'` |
| Гипотеза | `Hypotheses`, `H1…H9` | флаги в `src/data/hypotheses.json` |
| Событие шага | `SimEvent` | то, на что подписаны рендер и звук |
| Карта-лента | `ribbonMap` | верхняя зона экрана |
| Шеврон | `chevron` | знак поворота, слой 3 |
| Вращение колёс | `stepWheelSpin`, `frontRadius`, `rearRadius` | R25c: угол колёс вокруг оси копится в рендере, скорость = мировая скорость / радиус колеса модели (высота оси) |
| Следы передних колёс | `frontMarkSlip`, `frontMarksActive` | R24d: в DRIFT при `|slip| ≥ frontMarkSlip·slipFull` след R24c оставляют и передние колёса |
| Стартовый экран, пауза | `GameFlow`, `GamePhase` ('menu' / 'run' / 'pause'), `GameMenu` | R95: фазы игры вне симуляции; симуляция шагает только в 'run'; `menuEnabled` — без стартового экрана при `?menu=0` или `scenario` |
| Трасса для дрифта | `drift-lab` | `?track=drift-lab`: прямая, широкий medium, шпилька hard, S-связки, sharp; 2554 сегмента |
