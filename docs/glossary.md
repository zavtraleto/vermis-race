# Глоссарий: термин → идентификатор в коде

Один термин — один идентификатор. Новое понятие сначала добавляется сюда.

| Термин | Идентификатор | Пояснение |
| --- | --- | --- |
| Шаг симуляции | `DT`, `step()` | 1/120 с |
| Тик | `tick` | номер шага с начала гонки |
| Состояние гонки | `RaceState` | плоский JSON: машины, тик, RNG |
| Машина (любая) | `Car` | игрок, соперник и трафик — одна структура с полем `kind` |
| Вид машины | `kind: 'player' \| 'rival' \| 'traffic'` | |
| Путь вдоль трассы | `z` | в сегментах |
| Боковая позиция | `x` | −1…1 = асфальт |
| Скорость | `speed` | 0…`vmax` |
| Боковая скорость | `vx` | полуширин/с |
| Руль (сглаженный) | `steer` | −1…1 |
| Накопленный курс | `heading` | интеграл кривизны по пути |
| Кадр ввода | `InputFrame` | `{ steer, brake, drift }` |
| Параметры машины | `CarParams` | набор `P` из brief; JSON в `src/data/cars` |
| Сцепление / дрифт | `state: 'GRIP' \| 'DRIFT'` | состояние автомата дрифта |
| Сторона дрифта | `dir` | −1 или 1; 0 в сцеплении |
| Счётчик вне дороги | `offTicks` | тики подряд с `|x| > 1` (R21) |
| Авто-дрифт | `autoDrift` | H3 C: дрифт, пока touch-руль отклонён дальше `autoDriftSteer` |
| Угол дрифта | `angle` | состояние машины, со знаком, `angle*dir ∈ [0, 1]`; догоняет руль (R22) |
| Удержание drift-ввода | `driftHeld` | drift-ввод прошлого тика; вход в дрифт только по фронту (R20) |
| Взвод входа в дрифт | `armTicks` | тики с фронта drift-ввода, пока он удержан; вход в дрифт возможен, пока `armTicks*DT ≤ driftArmTime` (R20) |
| Счётчик малого угла | `lowTicks` | тики подряд с `angle*dir < driftAngleExit` (R21) |
| Повторное касание | `retouchDrift` | H3 D: отпустил, вернул палец за `retouchWindowMs`, повёл вбок дальше `retouchSwipePx` |
| Объекты у трассы | `roadside` | фонари (`lamp`), билборды (`billboard`), строения (`building`); R32 |
| Фигура трассы | `figure` | именованный кусок трассы из словаря R31: `straight`, `kink`, `sweeper`, `hairpin`, `flick`, `esses`, `tightening`, `opening`, `carousel`, `double` |
| Дрифт на обочине | `driftOffroad` | H11: 1 — дрифт работает вне дороги (R21b), 0 — нет |
| Трасса | `Track` | лента сегментов |
| Сегмент | `Segment` | `{ curve, y, width, props }` |
| Кривизна | `curve` | знак: + вправо |
| Класс крутизны поворота | `curveClass: 'easy' \| 'medium' \| 'hard'` | значения в `src/data/tracks/curves.json` |
| Секция трассы | `TrackSection` | `{ enter, hold, leave, curve }` в сегментах |
| Холм | `hill` | R30: изменение высоты за секцию в длинах сегмента (+ вверх); `y` сегмента — высота в его конце, один easeInOut на всю секцию; сумма `hill` по кольцу = 0 |
| Отсечение за гребнем | `Projection.clipped` | R30: 1 = линия проекции не выше всех ближних линий, дорога и столбики за ней не рисуются |
| Объект у дороги | `Prop` | поле `layer` 2 или 3, класс коллизии |
| Класс коллизии | `collision: 'solid' \| 'destructible' \| 'none'` | |
| Поток (слипстрим) | `draft` | заряд 0…1 |
| Потолок скорости | `capMul` | максимум по источникам, не сумма |
| Соперник | rival | `kind: 'rival'`; главный соперник — `isNemesis` |
| Трафик | traffic | `kind: 'traffic'` |
| Гипотеза | `Hypotheses`, `H1…H9` | флаги в `src/data/hypotheses.json` |
| Событие шага | `SimEvent` | то, на что подписаны рендер и звук |
| Карта-лента | `ribbonMap` | верхняя зона экрана |
| Шеврон | `chevron` | знак поворота, слой 3 |
| Увёртка | `gripDodge`, `dodgeFadeA` | R85c: добавка к `vx` в GRIP от руля на прямых, гаснет к повороту `easy` на `vmax`; в курс не возвращается |
| Пол руля в дрифте | `driftMinU` | R83b: в DRIFT доля пальца `uc` не ниже пола — против руля дрифт всё равно поворачивает в свою сторону |
| Нырок | `driftDive`, `driftKnee` | R84b (снят автором 2026-11-20, T69; `driftDive` 0): добавка к цели движения в DRIFT внутрь, когда набранный угол выше колена |
| Возраст дрифта | `driftTicks` | R86e: тики текущего дрифта; 0 в GRIP |
| Долг скраба | `scrubDebt`, `debtTime` | R86e: скраб R86b, накопленный в первые `debtTime` с дрифта; платится скоростью при раннем выходе, потом прощается |
| Нарастание опережения | `leadRamp` | R85d: опережение дрифта набирает силу за `leadRamp` с от входа |
| Отставание камеры | `camPosX`, `camLagTau`, `camLagMax` | R27b: боковая позиция камеры в рендере догоняет `x` машины |
| Камера в дрифте | `camShiftX`, `camDriftShift`, `camRollDeg`, `camGripMul`, `camDriftTau` | R27c: сдвиг камеры внутрь поворота и наклон горизонта по углу кузова R89 (`g = θ/θ_full`, `θ_full = slipFull·slipDeg`); в GRIP доля `camGripMul`; прибавляется к R27b |
| Вращение колёс | `stepWheelSpin`, `frontRadius`, `rearRadius` | R25c: угол колёс вокруг оси копится в рендере, скорость = мировая скорость / радиус колеса модели (высота оси) |
| Следы передних колёс | `frontMarkSlip`, `frontMarksActive` | R24d: в DRIFT при `|slip| ≥ frontMarkSlip·slipFull` след R24c оставляют и передние колёса |
| Угол опережения | `leadDeg` | R89: часть угла кузова от опережения (`vx/(sp*latScale) − vel`) |
| Автодрифт | `driftEntry` 4, `autoSteer`, `autoHold`, `autoLook`, `autoNeed` | R81e (H16 E): вход в дрифт решает симуляция — поворот впереди требует не меньше `autoNeed` предела сцепления, руль в его сторону ≥ `autoSteer` удержан `autoHold` с; выход — отпускание (R82) |
| Счётчик автодрифта | `autoTicks` | R81e: тики подряд, в которые выполнены условия входа автодрифта; 0 вне GRIP |
| Запрос поворота впереди | `needAhead` | R81e: `max|curve|*sp*kYaw/gripA` по дороге на `autoLook` с вперёд; `side` — знак этой кривизны |
| Управление удержано | `input.drift` (вариант 4) | R81e: палец на экране / кнопка мыши / удержанная стрелка; само по себе дрифт не включает |
| Вход соперников | `rivalDriftEntry` | R81e: вариант входа в дрифт у копий параметров соперников (старт 3), независимо от игрока |
| Дрифт в каждом повороте | `driftEntry` 5 | R81f (H16 F): DRIFT = машина на сегменте поворота и `input.drift` (палец на экране / пробел); сторона — сторона поворота; выход — конец поворота или отпускание |
| Сегмент поворота | `cornerCurve`, `cornerSide` | R81f: сегмент с `|curve| ≥ cornerCurve`; `cornerSide` — знак его кривизны, иначе 0 |
| Просвет поворота | `cornerGap` | R81f: сегментов вперёд, в которых поворотный сегмент той же стороны продолжает дрифт |
| Конец поворота | — | R81f: под машиной и в `cornerGap` впереди нет поворотного сегмента стороны `dir` — выход в GRIP без оплаты |
| Тяга вниз (зона дрифта) | `driftPull` | R81g: палец, сдвинутый вниз от точки касания на `dy ≥ stickRadius*ширина*driftPull`, включает дрифт до отпускания (защёлка); вверх — не снимает; боковой границы нет |
| Дрифт по пальцу | `driftEntry` 3 (H16 D) | R81g: вход — палец (пробел) и руль ≠ 0, сторона — руль; выход — только отпускание или скорость; конец поворота дрифт не прекращает |
| Способ дрифта на касании | `H19_touchDrift`, `touchDrift` | R81h: A — «Рывок вбок» (`flickMs`, `flickDist`), B — «Вниз» (R81g, `driftPull`), C — «Нижняя зона» (`driftZoneFrac`); читается стиком при каждом касании |
| Рывок вбок | `flickMs`, `flickDist` | R81h A: палец ушёл вбок на `|dx| ≥ R*flickDist` в первые `flickMs` касания — дрифт до отпускания; после окна это касание дрифт не включит |
| Нижняя зона дрифта | `driftZoneFrac` | R81h C: касание, начатое в нижней доле `driftZoneFrac` зоны руля, — дрифт с касания до отпускания |
| Стартовый экран, пауза | `GameFlow`, `GamePhase` ('menu' / 'run' / 'pause'), `GameMenu` | R95: фазы игры вне симуляции; симуляция шагает только в 'run'; `menuEnabled` — без стартового экрана при `?menu=0` или `scenario` |
| Доля удержания | `h` | R83c: доля угла, при которой дрифт держит дорогу на этом повороте: `min(1, driftPush*max(0, A*dir)/driftLat)` |
| Ход линии в дрифте | `cornerSpan`, `cornerMinU` | R83c: `uc = clamp(h + cornerSpan*u, cornerMinU, 1)` — руль двигает линию вокруг удержания, угол не ниже `cornerMinU` |
