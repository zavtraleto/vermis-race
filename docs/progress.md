## Что есть в игре
- Каркас: фиксированный шаг 1/120 с и интерполяция, dev-панель (`?dev=1`), счётчик кадра (`?hud=1`), `check` / `test` / `smoke` / `shot`, бот и гейт (`npm run bot && npm run gate`), деплой на GitHub Pages.
- Дорога: псевдо-3D из сегментов, кривые, перепады высот (R30), объекты у дороги (R32), фигуры и трассы (R31, R31b: `test-twisty`, `drift-run`, `drift-lab`).
- Машины: игрок — 3D-модель NSX, соперники и трафик — свои модели; колёса крутятся и рулят (R25b, R25c), дым и следы шин (R24b–R24d).
- Гонка: трафик (R70+), коллизии v2 (R100–R113), аварии (R47–R49), поток (R50–R53), соперники с местами и пулом (R60–R67), меню старта и паузы (R95).
- Визуал [решения автора 2026-11-19]: настоящий 3D-рендер отброшен, картинка на псевдо-3D и спрайтах; палитра 16 цветов на уровень; первый уровень — «Сад спящих богов». Печатный вид (`?print`) автор отверг: «всё мельтешит… безвкусно» — делаем по одной части и показываем (см. `docs/art-bible.md`).
